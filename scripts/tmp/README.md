# scripts/tmp/ — 一時作業スクリプト置き場

使い捨て（単発）の作業用スクリプトは、**必ずこのフォルダの中に作成する**こと。

## ルール

- このフォルダ内は `README.md` を除き **`.gitignore` で追跡対象外**。ここに置いたスクリプトはコミットされない。
- **作業が終わったら削除する。** コミットされないとはいえ、作業完了時に不要なものは消してフォルダを空に戻すこと。
- 恒久的に使うツール（`generate_sitemap.py` / `cloudinary_migrate.py` / `_generate_search_index.py` や各種テンプレート）は、ここではなく `scripts/` 直下に置く。

## 一時スクリプトの例

- 特定イベント／画像の一括アップロード（`upload_*`）
- 特定ページの一括生成・一括補正（`generate_*` / `build_*` / `fix_*` / `convert_*`）
- データ移行・突合の使い捨て処理（`merge_*` / `migrate_*`）

これらは出力（HTML・Cloudinary画像・data/更新）が成果物であり、スクリプト自体はリポジトリに残さない。
