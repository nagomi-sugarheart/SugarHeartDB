# CreateYoutube スキル：YouTube用素材ファイルの生成（Cowork作業用）

イベントコミュ動画のYouTube設定（概要欄・チャプター・字幕）用の素材ファイル一式を生成する。
後ほどCowork（別のAIエージェント）がこれらのファイルを使ってYouTube Studioで設定作業を行う。

**前提**: CreatePage スキルで生成したイベント別のマージ済みJSON（例 `scripts/merged_commu.json`、
`scripts/merged_hny_commu.json` など `merged_{event}_commu.json` 形式）が存在すること。対象イベントのファイル名を使う。

**参考実装（テンプレート）**: `G:\マイドライブ\コミュ\YouTube_凸凹スピードスター\generate_youtube_files.py`

## ユーザーが毎回指定するもの
1. **出力先フォルダ**（リポジトリ外。Gドライブ `G:\マイドライブ\コミュ\...` かダウンロードフォルダ）
2. **YouTubeのURL**（動画ID）
3. 対象イベント（merged_commu.json の場所が凸凹と異なる場合はそのパス）

## 生成するファイル（5点）
出力先に `YouTube_{イベント名}` フォルダを作成し、以下を格納する。

| ファイル | 内容 |
|---|---|
| `generate_youtube_files.py` | 下記3ファイルの生成スクリプト（再生成できるよう同フォルダに保存） |
| `subtitles_ja.srt` | 日本語字幕（全セリフ＋タイトルカード・場所表示） |
| `chapters.txt` | チャプター一覧（`M:SS ラベル`） |
| `description.txt` | 概要欄にそのまま貼れるテキスト（チャプター込み） |
| `README_Cowork.md` | Cowork向け作業指示書 |

## タイミング規則（最重要）
- merged_commu.json の `t` は**セリフが表示されきった時刻**。
  **各イベントの開始時刻＝直前イベントの t** とみなす
- 全セクションを順番どおり1本のイベント列に連結して処理する
- セクション先頭（trailer以外）に**タイトルカードイベント**を挿入する。
  テキストは `{title} {サフィックス}`（OP/1話…/ED）、t は `title_frame` のファイル名 `NNNN_dialogue_{秒}s.jpg` からパース
  - **例外: セリフ始まりの話**（`title_frame` が先頭セリフのフレームと同一＝映像に話タイトルカードが無い話。
    Happy New Yeahの第2話等）は、タイトルカード字幕を挿入せず、先頭セリフに**チャプターだけ**立てる
    （挿入するとタイトルカードと先頭セリフが同一tになりゼロ長字幕が発生する）
- `t` が null の行（フレーム抽出漏れ）は、前後の確定 t の間に**均等配分で補間**する
  - **最終行が shotなし（t=null）の場合**は右アンカーが無いので、直前tから一定間隔（例2.5秒）で
    加算する。同一tに潰すと末尾がゼロ長字幕になる（Happy New YeahのED末尾で対応）
- 動画冒頭にテキスト未収録の映像（Twitter予告・告知バナー等）がある場合、最初のイベントの開始は
  その想定時刻（凸凹では30.0秒、Happy New Yeahは冒頭が告知バナーのため0.0秒）
- 最後の字幕の終了時刻は t + 5秒
- **生成後、チャプター秒とページの `data-start` が全話一致するか必ず照合する**。
  shotなし行の補間により末尾話がズレることがある（EDは直前のLIVE演出のshotなし行を挟むため注意）

## 各ファイルの仕様

### subtitles_ja.srt
- 連番・タイムコード `HH:MM:SS,mmm`。開始=直前イベントのt、終了=自身のt（連続字幕）
- セリフ行: `（話者名）テキスト`。話者「P」は `（プロデューサー）`
- ナレーションでテキストが既に（）で始まる場合はプレフィックスなし
- scene/stage/header/sub 行: `【テキスト】`
- 直後の行と t が重複する sub 行（凸凹の「Twitter告知」等）はスキップ

### chapters.txt
- `0:00 {冒頭のラベル}` を先頭に（YouTubeチャプターは0:00必須）
- 各話の開始 = タイトルカードイベントの開始時刻（=直前イベントのt）を秒切り捨てで `M:SS`
- ラベル例: `OP 結成！ふたりは魔法少女`、`第1話 難関！ステージまでの道`
- **昇順・間隔10秒以上を検証**すること

### description.txt
- 動画の説明（収録内容: 予告・OP・第1話〜第5話・ED）
- イベント情報（種別・開催期間・イベント楽曲と歌唱者・報酬SR）
- チャプター一覧（chapters.txtと同内容。概要欄のタイムスタンプでYouTubeが自動認識）
- SugarHeartDBのイベント詳細ページへのリンク
  `https://nagomi-sugarheart.github.io/SugarHeartDB/Deresute/Event/{ページ}.html`
- ハッシュタグ（#デレステ #シンデレラガールズ ＋出演アイドル名）

### README_Cowork.md
- 対象動画URL・現状（何が未設定か）・推奨タイトル案
- 各ファイルの使い方（description.txt→概要欄へ貼り付け、字幕はSRTを言語「日本語」でアップロード、チャプターは概要欄で自動認識のため入力不要）
- タイミング精度の注意（表示完了時刻ベースの近似・補間行あり・冒頭のテキスト未収録範囲）

## 実行と検証
- 生成はSonnetサブエージェントに委任してよい（本スキルの仕様を丸ごとプロンプトに含める）
- 検証: SRTの先頭3件と最終件、chapters.txt全行、字幕総数、タイムコード昇順を確認して報告する
- **リポジトリ内には何も作成・変更しない**（出力はすべて指定フォルダへ）
- ページ側の再生ボタン（`data-start`）とチャプター時刻が一致していることを確認。ズレていればページ側も補正する
