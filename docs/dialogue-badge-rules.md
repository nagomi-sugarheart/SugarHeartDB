# 会話バッジ表記ルール

サイト内のアイドル間のやり取りページにおける、話者名バッジの統一ルールを定める。

## 概要

すべての会話バッジは **パーソナルカラー** を背景色とし、セリフ本文と組み合わせて表示する。
カラーデータは `data/cgss_idols.csv` を参照し、`components/idol-badge.js` が自動で適用する。

---

## バッジの種類

### 1人のアイドルが話す場合

- バッジ背景: そのアイドルのパーソナルカラー（`イメージカラー` 列）
- バッジ文字色: 背景の輝度に応じて自動判定
  - 輝度 > 60% の明るい色（例: 千鶴の `#99e3fc`、きらりの `#ffd100`）→ 濃色 `#222`
  - それ以外 → 白 `#fff`

### 2人のアイドルが同時に話す場合

- バッジ背景: 2人のパーソナルカラーを **100度の傾きで縦割り（左: Aのカラー、右: Bのカラー）**
- バッジ文字色: 白 `#fff`（可読性確保のためテキストシャドウ付き）

### 3人以上 / 「一同」の場合

- バッジ背景: 登場アイドルの **属性カラー** で縦割り（1〜3色）
- 属性の優先順位: **キュート ▶ クール ▶ パッション**
- 属性カラー:
  - キュート: `#ef2782`
  - クール: `#006aff`
  - パッション: `#f49207`
- 1属性のみ: 単色
- 2属性: 100度の傾きで2色縦割り
- 3属性すべて: 3等分の3色縦割り

## HTMLマークアップ規則

### 形式A: `.dialog` 形式（Event_KirakiraModelChallenge 等）

```html
<div class="dialog">
  <div class="body">
    <div class="line-head">
      <span class="speaker" data-who="心">心</span>
    </div>
    <div class="text">セリフ...</div>
  </div>
</div>
```

- `data-who` 属性に話者名を設定する
- 2人同時: `data-who="心・千鶴"`（`・`区切り）
- 3人以上/一同: `data-who="一同"`

### 形式B: `.script-row` 形式（シンデレラヒストリー・カミングTV・リフレッシュルーム等）

```html
<div class="script-row" data-who="心">
  <span class="who">心</span>
  <div class="line">セリフ...</div>
</div>
```

- `data-who` 属性は `.script-row` 要素に設定する（`.who` スパンではない）
- 2人同時: `data-who="心・千鶴"`（`・`区切り）
- ステージディレクション（地の文）: `class="script-row stage-direction"` を使用

### 形式C: `.ud-dialogue` 形式（ユニットページ）

```html
<div class="ud-dialogue">
  <p class="line">
    <span class="speaker">千鶴</span>
    セリフ...
  </p>
</div>
```

- `.speaker` スパンのテキスト内容がアイドル名として使用される
- `data-who` 属性を設定してもよい（優先される）
- 2人同時: スパンのテキストまたは `data-who` に `心・千鶴` と記述

## カラーデータの参照先

`data/cgss_idols.csv` の列構成:

| 列名 | 説明 |
|------|------|
| アイドル名 | フルネーム |
| 名前 | HTMLに記載する短縮名（バッジテキスト） |
| 属性 | キュート / クール / パッション |
| 属性カラー | 属性に対応するカラーコード |
| イメージカラー | パーソナルカラー（バッジ背景色として使用） |

新しいアイドルを追加する場合は `data/cgss_idols.csv` に行を追加するだけでよい。
CSS や JS の変更は不要。

---

## 特殊な話者の扱い

| 話者名 | バッジの見た目 |
|--------|-------------|
| `一同` / `アイドル他` | 3属性カラー3色縦割り |
| `P`（プロデューサー） | ダークグレー（`var(--sh-text)`） |
| `ナレーション` | 透明背景、破線ボーダー |
| （空） | バッジなし（ステージディレクション用） |

## 実装ファイル
